# 公開版への一括コード反映

参照元は `Taiga-Sekida/jphacks_2026_unity_sim` の `4e6bcd3153b2a1bbde140645d3840dbdc0ce40fd`。公開版の PR #24 のセンサー接続を含め、残りの機能を1本の PR で確認できる形にまとめた。

## 含めた機能

- 並行走行と譲り合い、積載・旋回・停止の物理モデル、歩行者との接触判定。
- 来店、案内、席別の注文と配膳、食事、皿回収、退店、待機機の巡回。
- 人が停止・引き継ぎ・復帰を決める操作画面、定型会話と質問への固定応答。
- Unity の状態と店内配置を監視 hub に渡し、減速提案を受け、人が復帰を確認する連携。
- 自作の人物・料理・家具の素材、生成コード、検証入口。
- センサーの最新の判定と、社内 PDS の起動待機・ローカルビューア向け応答。

ユーザーの選択に従い、センサーが Limited を判定したら `capability: Limited`、`final: Hold` として停止し、人の KEY2 を待つ。能力表の皿回収の許可と、最終状態による停止は別のもの。1回だけ静かな測定を挟んでも回数を保ち、2回続けて静かなら数え直す。

## 公開版で維持したもの

外部設定と公開サンプルの分離、不正設定の拒否、安全なシーン生成とバックアップ、既存の CI、Unity 統合検証、手動 STOP とセンサー Hold の分離を維持した。既存ファイルの Unity GUID は置き換えていない。

従来の歩行者・日本語操作デモは、互換用のクラスとして残した。`-guardianPedestrianDemo` / `-guardianInteractionDemo` では、従来の単線通路と操作を使う。通常起動では元実装の新しい来客・並行走行・操作画面を使う。

録音音声、権利未確認の Nekobot、PV 用プロジェクトは追加していない。会話の文字データは含む。音声とスマートフォンの中継サーバーは別構成で、スマートフォン用クライアントは `-guardianPhoneDemo` を指定したときだけ有効にする。追加モデルなしで自作の代替形状を使える。

## 検証

ライセンス済み Unity 6000.3.12f1 の別作業コピーで、以下を実行する。PlayMode を使う検証も、表示なしの検証であり、実クリック・録音・実機の確認とは分ける。

| 入口 | 確認する内容 |
|---|---|
| `GuardianIntegrationBatch.Verify` | 公開設定・能力表・旧歩行者・旧日本語入力・センサー15ケース・シーン生成 |
| `GuardianDynamicsEvidence.Headless` | 実際の Rigidbody を使う物理モデル60ケース |
| `GuardianSafetyBoundaryEvidence.Headless` | 安全境界15ケース |
| `RiggedGuestValidation.HeadlessFamily` | 自作人物4種類の生成と GUID、着席や解放の PlayMode 検証 |
| `GuardianInteractiveSetup.Headless` | 並行稼働、入力途絶、停止・復帰、操作デモの進行 |

追加検証は、終了コードに加え、新しく作った結果 JSON の `status: PASS` を確認する。GitHub Actions ではセンサー22件、監視48件、共有33件、PC 側の鍵18件、出口8件、ローカル PDS 応答2件、Windows 起動6ケースと既存の静的検査を実行する。Unity Editor の実行はローカルで行う。

実ロボットの安全性、実センサーと PSoC 6 のピン・LED、マイク入力と録音音声、長時間の実演・描画は未検証。物理モデルの数値は試験用の仮定で、実機の同定値や安全認証を示さない。
