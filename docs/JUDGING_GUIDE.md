# 審査デモガイド

## このデモで伝えること

ロボもりは、故障を一律の停止として扱うのではなく、機体状態ごとに実行可能な
仕事を制限し、複数ロボット間で安全に仕事を継続する考え方を示す公開シミュレーターです。
Unity内の値と判定を可視化する審査用デモであり、実機の安全認証やセンサー性能を
証明するものではありません。

## 事前準備

1. Unity 6000.3.12f1でプロジェクトを開きます。
2. `Guardian > Scene Tools...`から公開デモシーンを生成します。
3. 同じ画面の`Validate Saved Scene`を実行します。
4. `Assets/Scenes/GuardianRestaurant.unity`を開きます。
5. Consoleにコンパイルエラーがないことを確認します。
6. ローカル第三者モデルを使わない公開状態で、最初の通し確認を行います。

シーン再生成は既存ファイルを`Library/GuardianSceneBackups`へ退避します。
発表用のローカル素材を適用済みの場合は、再生成前に必ずバックアップを確認してください。

## 5分デモの流れ

### 1. 通常配膳

Play Modeを開始します。既定はPhysicsモードです。右側パネルから
`Soup T1`、`Food T2`、`Return T3`を追加し、Robot A / B / Cへ仕事が
割り当てられ、実際のサービス地点へ移動することを示します。

説明点:

- 仕事の種類だけでなく、機体状態と通路予約を見て割り当てる
- 積載物とタスクの所有関係を維持したまま動く
- 表示上の完了ではなく、物理的な到着を待つ

### 2. 能力制限と再割り当て

Robot Bを`Warning`、続けて`Limited`へ変更します。公開版の能力マトリクスは
NormalがSoup / Food / Return、WarningがFood / Return、LimitedがReturnのみです。
状態変更後に新しいタスクを追加し、不適格な種類がBへ新規割り当てされないことを示します。

説明点:

- 閾値の数値自体ではなく、状態から許可される仕事を明示する
- 緊急停止中は状態にかかわらず新規仕事を許可しない
- 公開サンプル値は実機の安全限界ではない

### 3. 人との交差

歩行者デモを有効にした起動では、スタッフが通路を横断します。ロボットが
予測距離と物理障害物検出で停止し、人が通過したあと公開設定のクリア時間を経て
再開することを示します。

このデモは`-guardianPedestrianDemo`起動引数を明示したときだけ有効です。
通常起動の挙動は変更しません。

### 4. 日本語操作

`-guardianInteractionDemo`も指定した起動では、日本語パネルから`状況`、
`A 停止`、`実行`、`A 復帰`、`実行`の順に操作します。状態変更は確認待ちとなり、
別の`実行`入力があるまで反映されません。

説明点:

- ローカルの定型文字入力で、音声・外部API・生成AIは使わない
- 複数対象、未知のRobot、制御文字、長大入力を拒否する
- リセット、状態変化、期限切れ後の古い確認は拒否する

## 起動引数付きデモ

Unity Editorを閉じ、Unity実行ファイルへ次の引数を追加してプロジェクトを開きます。

```text
-projectPath <repository> -guardianPedestrianDemo -guardianInteractionDemo
```

公開設定ファイルを明示的に使う場合だけ、さらに`-guardianPublicSettings`を追加します。
引数なしの通常起動は、従来どおりシーンにシリアライズされた公開デモ既定値を使います。

## デモ後に示す証拠

- GitHub上の段階的なPR履歴
- `Guardian > Validate Saved 3D Simulator Scene`の成功ログ
- GitHub Actionsのチェック結果
- ライセンス済み環境での`GuardianIntegrationBatch.Verify`成功ログ
- 公開版と発表版の差分、および第三者素材のライセンス

## 説明してはいけないこと

- 公開サンプルの閾値を実機の安全限界・校正値・推奨値として説明しない
- Unity内の真値による歩行者観測を、実センサーの検出精度として説明しない
- GitHub Actionsの静的成功を、PlayMode・描画・実機動作の成功と説明しない
- リポジトリに含まれないモデル・音声・演出を、公開版だけで再現できると説明しない
- `.gitignore`追加によって、過去に公開した値が履歴から消えたと説明しない

## 公開版と発表版の差分

| 項目 | 公開版 | 発表時に追加される可能性があるもの |
| --- | --- | --- |
| 制御・状態管理 | 公開対象コードと公開デモ既定値 | 実運用設定はリポジトリ外 |
| レストラン | 自作FBX、Prefab、Material | 外観調整 |
| Robot外観 | 自作の簡易表示 | 許諾確認済みローカルモデル |
| 操作 | 文字UI | 音声・外部連携は公開版に含めない |
| 検証 | 静的CIとUnityバッチ入口 | PlayMode、描画、実機確認は別記録 |

差分がある場合は、デモ開始前にどちらの構成かを明示します。
