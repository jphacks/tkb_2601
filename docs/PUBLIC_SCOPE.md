# 公開範囲と検証

## 公開方針

審査時にコードを確認できるよう、
公開対象として選んだUnityシミュレーターの実装を収録します。

非公開のモデル、第三者素材、秘密鍵、個人情報、
内部の特許出願資料は追加しません。

## 公開版と完全版

### 公開版

- 公開対象の制御コード
- Unity Editorツール
- 設定ファイル
- 公開可能なレストラン素材
- 静的検証用CI

### 発表時の構成

公開版には含まれないモデル、アニメーション、
音声などが使用される場合があります。

公開版と発表時の構成は完全には一致しません。

## 制御設定の分離

`Assets/StreamingAssets/Guardian/guardian-settings.public.json` は審査用デモの例です。
ここにある値は実運用の安全限界、校正値、推奨値ではありません。

実運用設定は `.guardian/guardian-settings.private.json` に置くか、
`GUARDIAN_SETTINGS_PATH` または `-guardianSettingsPath <path>` で
リポジトリ外のJSONを明示的に指定します。private設定はGit管理外で、
公開用ビルドにも自動では含まれません。

private設定がなく外部指定もない通常起動では、従来どおりUnityにシリアライズされた
デモ設定を使います。`-guardianPublicSettings` を指定すると、公開サンプルを
明示的に読み込めます。設定は利用前にスキーマ、必須値、範囲、大小関係を
検証し、明示指定したファイルがない場合や不正な場合は起動を失敗させます。

なお、すでに公開済みの値は `.gitignore` の追加や本変更だけでは
Git履歴、fork、clone、キャッシュから消えません。秘密として扱う必要がある
既公開値は別途ローテーションし、必要なら履歴書き換えと関係者への連絡を
独立した手順として行う必要があります。

## 歩行者安全デモの範囲

`-guardianPedestrianDemo` を指定したPhysicsモードでは、公開可能な既存の
スタッフモデルを1人の歩行者として横断させます。ロボットは現在速度と
直前の移動意図から接近を予測し、危険が残る間は移動出力をゼロにします。
さらに既存の物理BoxCastによる障害物ブレーキも残しています。

歩行者用の数値は公開サンプル設定です。private設定の実運用値をコピーした
ものではなく、実機安全限界や適合性を示しません。観測値もUnity内の真値で、
実カメラや実センサーの性能を再現していません。通常起動では無効のため、
従来のタスク割当、状態判定、許可マトリクス、デモの初期挙動は変わりません。
PR #7形式の既存設定に歩行者項目が全くない場合は公開デモ既定値を補完します。
歩行者項目を1つでも指定する新設定では、6項目すべてが必要です。

Unityバッチ検証入口 `Guardian.UnitySim.Editor.GuardianPedestrianBatch.Verify` は、
交差、離れた平行移動、初期重なり、不正数値のfail-closed判定を確認します。

## 日本語操作・会話デモの範囲

`-guardianInteractionDemo` を指定したPhysicsモードでは、日本語の定型文字入力で
状態照会と緊急停止・復帰を操作できます。状態を変更する指示は確認待ちにし、
別入力の `実行` があるまで反映しません。確認後に対象状態やシナリオが変化した場合、
15秒を超えた場合、歩行者安全停止中に復帰を求めた場合はfail-closedで拒否します。

この公開版はマイク入力、音声認識、音声合成、録音音声、生成AI、外部API、
ネットワーク通信を含みません。非公開側の会話文や音声素材はコピーしていません。
入力内容を外部へ送信せず、応答は現在の公開シミュレーション状態だけから生成します。

日本語表示用のNoto Sans JP Regular 2.004は、フォント内の著作権表示と
SIL Open Font License 1.1を確認したファイルだけを同梱します。フォントはOFL-1.1の
ままであり、リポジトリのMITライセンスへ変更しません。出所、ハッシュ、ライセンスは
`Assets/Art/Fonts/README.md` と同じフォルダーのOFL本文に記録します。

Unityバッチ検証入口 `Guardian.UnitySim.Editor.GuardianInteractionBatch.Verify` は、
全角正規化、複数対象・未知対象・制御文字・長大入力の拒否と、フォントの
サイズ・SHA-256・OFL本文を確認します。

## 非公開モデル

再配布条件を確認できていない第三者モデルや、
公開対象外の独自モデルは追加しません。

モデル本体だけでなく、再生成可能なソース、
詳細な形状データについても公開可否を確認します。

## Editorシーン生成

`Guardian > Scene Tools...` は公開デモシーンの生成、表示、検証をまとめた入口です。
生成処理は加算シーンで動作するため、開いている別シーンを自動で閉じません。
再生成では未保存変更の扱いと上書きを確認し、既存シーンを
`Library/GuardianSceneBackups`へコピーしてから置き換えます。生成失敗時は
そのコピーから元のシーンを復元します。

生成後は、Simulatorが1つ、IDが一意なRobotが3台、公開レストラン素材の個数・
メッシュ・マテリアル・通路クリアランスが正しいことを検証してから保存します。
Build Settingsへは対象シーンを追加または有効化し、既存の項目を削除しません。

シーン生成はリポジトリ内の公開コードと公開可能な自作素材だけを使用します。
private設定、非公開モデル、音声、権利未確認素材を探索・取込する処理はありません。
そのため発表時にローカル素材を追加した構成とは外観が異なる場合がありますが、
既存の公開デモ挙動とシリアライズ済み既定値は変更しません。

## 動作検証

以下は確認予定の項目です。
すべて成功済みという意味ではありません。

- [ ] 新規cloneでUnityプロジェクトを開ける
- [ ] Consoleにコンパイルエラーがない
- [ ] シーンを生成できる
- [ ] シーン再生成前にバックアップされ、既存Build Settings項目が維持される
- [ ] 生成した公開シーンが配置・素材バリデーションを通過する
- [ ] PlayModeで起動できる
- [ ] ロボットの状態変化を確認できる
- [ ] タスクの割り当て・引き継ぎを確認できる
- [ ] 公開版と発表版の違いを記録した
- [ ] private設定なしで従来の審査用デモが動作する
- [ ] `-guardianPublicSettings` で公開サンプルを読み込める
- [ ] 不正な設定と欠落した明示指定ファイルが拒否される
- [ ] 歩行者横断時にロボットが停止し、通過後に再開する
- [ ] 歩行者停止でタスク、積載、能力状態が変化しない
- [ ] 日本語パネルで状態照会、停止確認、実行、復帰確認を操作できる
- [ ] リセット後の古い確認と歩行者安全停止中の復帰が拒否される

## CIについて

GitHub Actionsの静的検証成功は、
Unityでの実行成功を保証するものではありません。

Unity 6000.3.12f1 のコンパイルと設定ロード検証は、ライセンス済み環境で
次のバッチメソッドを実行します。

`Guardian.UnitySim.Editor.GuardianSettingsBatch.Verify`

この検証は、無指定時に既存設定を維持すること、公開サンプルを明示的に
読み込めること、明示指定した欠落ファイルを拒否することを確認します。

シーン生成のローカルバッチ検証入口は次です。

`Guardian.UnitySim.Editor.GuardianSceneBatch.Verify`

この検証は一時的な公開デモシーンを生成・検証し、既存Build Settings項目が
保持されることを確認した後、一時シーンと設定変更を元に戻します。

## 権利関係

第三者のモデル・音声・画像・フォント等については、
各権利者の利用規約・許諾条件を確認してください。

クレジット表記のみで再配布権が付与されるわけではありません。

## 注意事項

.gitignoreは、すでにGitに追跡されたファイルや
過去のコミットを非公開にする仕組みではありません。

公開用のビルド・ZIP・Artifactsについても
非公開素材の混入を別途確認する必要があります。
